# some VScode extensions 

## visual enhancement
- material theme: A visually appealing and customizable theme for Visual Studio Code.
- Material Icon Theme: Adds a set of Material Design icons to complement the Material Theme.
- Indent rainbow: Colors the indentation levels in your code for improved readability.

## development utility 
- random everything: Generates random data for testing purposes, such as names, addresses, and numbers.
- Toggle Quotes: Quickly switch between single and double quotes in your code. 
- Better Comments: Helps you create more readable and organized comments in your code.
- codesnap: Captures and shares screenshots of your code.
- TODO Highlight: Highlights TODO comments in your code for easy identification.

## productivity tools
- project manager: Helps you manage and switch between multiple projects in Visual Studio Code.
- peacock: Allows you to change the color of your Visual Studio Code workspace for better organization and visual distinction between projects.
- auto open markdown preview: Automatically opens the markdown preview when you open a markdown file.
- snippet creator: Allows you to create and manage custom code snippets for faster coding.

- gitlens: Provides advanced Git capabilities and insights directly within Visual Studio Code, including blame annotations, code authorship, and repository history.
